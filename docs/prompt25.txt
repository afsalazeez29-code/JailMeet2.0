PART 2 — FIX ONLY CRITICAL FINDINGS
============================================================

Only proceed with this part for items the audit classified as CRITICAL. Do not "clean up while you're in there" — moderate and low-priority items stay untouched in this task, even if they're easy to fix. Each fix must be small, scoped, and verified independently.

For each critical finding, apply the narrowest fix that resolves it, following these standing rules:

CSS scoping fixes:
- Global CSS stays limited to true global concerns only (Tailwind setup, body defaults, CSS variables, reset, shared typography) — move anything else out of globals.css into the correct role-scoped layout or a CSS Module
- Legacy CSS for each role stays isolated to that role's layout.tsx — never loaded in the root layout or another role's layout
- Remove genuinely duplicate stylesheet imports (same file loaded twice) — keep exactly one load point per stylesheet

DOM-manipulation fixes:
- Any direct document/window/body access must be inside a "use client" component, inside a useEffect, with proper cleanup (e.g. removeEventListener, clearing any added classes) on unmount

"use client" fixes:
- Add "use client" only where genuinely required (confirmed hook/browser-API usage) — do not add it preemptively or to files that don't need it
- Do NOT remove "use client" from a file unless the audit specifically confirmed it's unnecessary AND you've verified nothing in that file's render path depends on browser-only behavior

Unused asset cleanup:
- Only remove a CSS/asset file if the audit confirmed with reasonable confidence that nothing references it — when in doubt, leave it and just note the uncertainty in your report rather than deleting

Do NOT in this part:
- Extract any large page.tsx into smaller components (that's future Phase 3/4 work, not this task)
- Move any component from frontend/components/ to frontend/src/components/ (that's future Phase 6/gradual work, not this task)
- Create reusable UI primitives (LoadingState, ErrorMessage, StatusBadge, etc.) even if duplication was found — that's future Phase 6 work
- Rename any Bootstrap/legacy CSS class
- Touch any backend code

After each individual critical fix, run:
npm run typecheck
npm run build

Confirm both pass before moving to the next critical fix. If a fix causes a regression, revert that specific fix and report it rather than pushing forward.
