After aos.js finishes loading, initialize it:

(window as any).AOS?.init({
  duration: 600,
  once: true,
});

If JSX content loads dynamically (client-side render after mount), also call:

(window as any).AOS?.refreshHard();

Without this initialization, any element using data-aos="fade-up" (or similar)
will remain invisible, since AOS's own CSS hides elements by default until
initialized. This is likely the primary cause of "missing" sections — the JSX
may already be present but invisible due to uninitialized AOS.
